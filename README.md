# Python Learning Journey

Learning Python from the basics toward quantitative finance (NumPy, Pandas).
Each project lives in its own folder with a small README. This log is the record of the climb.

## Learning Log

| # | Project | Date       | New concepts                                   | What I learned                                                                                                                                                                                                                                                         |
|---|---------|------------|------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Number guessing game | 2026-07-28 | `random`                                       | `input()` always returns text, so I had to `int()` it before comparing. Also got used to indentation replacing braces.                                                                                                                                                 |
| 2 | FizzBuzz | 2026-07-29 | `for`, `range()`                               | `range(1, n+1)` is exclusive on the upper end. Modulo I already knew from Java.                                                                                                                                                                                        |
| 3 | CLI calculator | 2026-07-29 | functions, branching on operator, try / except | Split each operation into its own function and dispatched with if/elif on the user's choice. Learned that dividing ints in Python 3 still returns a float.                                                                                                             |
| 4 | Multiplication drill | 2026-07-30 | `time`, f-strings, `while True` / `break`      | `time.time()` is only useful taken twice and subtracted. `while True` + `break` is the right shape for a "play again?" loop when I don't know the number of rounds up front.                                                                                           |
| 5 | Unit converter | 2026-08-01 | dictionary dispatch (functions as values) | Stored each function in a dict keyed by menu number, so one lookup replaced the whole if/elif chain. Learned functions are values you can pass around, `func` stores it, `func()` calls it. Also that `continue` returns to the menu while `return` kills the program. |
| 6 | Word frequency counter | 2026-08-01 | file I/O (`with open`), `dict.get()` counting, `collections.Counter`, list comprehensions | Counted words with `counts.get(word, 0) + 1`, then refactored the whole loop + sort into `Counter(words).most_common()`. Learned that `.strip()` and `sorted()` return new values that vanish if I don't assign them, and that `open()` needs `encoding="utf-8"` on Windows or an em dash comes out as mojibake. |
| 7 | To-do list CLI | 2026-08-02 | lists (`append`, `del` by index), `enumerate(start=1)`, file persistence (write side, `"\n".join` / `.split`) | Kept tasks in a list and persisted them by joining on `\n` to save and splitting to load. The round-trip has a trap: `"\n".join([])` writes `""`, and `"".split("\n")` reads back `[""]` not `[]`, so an "empty" list showed a phantom blank task until I stripped and guarded for empty content. Learned `del tasks[i]` deletes by position while `.remove()` deletes by value (wrong one with duplicates), and that indexing needs a range check or `del tasks[9]` crashes and `del tasks[-1]` silently kills the last item. |
| 8 | Mental-math trainer (Zetamac) | 2026-08-04 | `random.choice`, live countdown with `time.time()` in the loop condition, append mode (`open(..., "a")`), `datetime.now().strftime()`, negative-index slicing (`lines[-20:]`) | Timed the whole session by reading `time.time()` live in the `while` condition instead of subtracting two readings after the fact. Learned append mode `"a"` stacks onto the file instead of wiping it like `"w"`, but only if every write ends in `\n` — I forgot it first and the whole log smeared onto one line. `readlines()` keeps the trailing `\n`, so I needed `.strip()` or print double-spaces. `lines[-20:]` shows the last 20 and never errors on a short file, unlike indexing a single element. Dodged float comparison in division by presenting `product / first` so the answer is always whole. |
| 10 | Dice/coin simulator | 2026-08-05 | `collections.Counter` as an auto-initializing tally, empirical vs theoretical probability | Replaced my one-variable-per-outcome counting with a `Counter`, which returns 0 for keys it's never seen so `counts[flip] += 1` works on the first flip with no seeding — the thing a plain dict can't do. That's what let the die scale to six faces without six variables. Hit the classic float trap: `round(x, 4) * 100` printed `57.9999999` because rounding *then* multiplying re-introduces the error, so I round last, right before display. Also caught a fall-through bug where an invalid menu choice printed an error but kept going without `continue`. |
